Progressive Path Tracer

Physically-based rendering with diffuse, metal, and glass materials — up to 8 ray bounces per path. Each frame adds one sample per pixel; watch the noise melt away as the image converges. All math runs in Rust compiled to WASM; JavaScript only schedules frames and reads the clock.
